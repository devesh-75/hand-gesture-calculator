# Hand Gesture Calculator ✋🧮

A real-time calculator using hand gestures powered by ml5.js.

## Features
- Finger detection (0–5)
- Addition, Subtraction, Multiplication, Division
- Real-time webcam input

## Tech Stack
- HTML, CSS, JavaScript
- ml5.js (Handpose)
